动手之前，先看清市场

探索想法背后的市场。

IdeaProbe 是给创业者、独立开发者和创作者使用的开源 AI 市场调研工具。发现相关产品，阅读实际可获得的用户评价，把想法整理成一份可追溯来源的报告。

本地启动在 GitHub 查看代码

MIT 许可证 · 自备 API key · 支持中文与英文

发现相关产品

同时搜索 Bing RSS、Tavily 和 Brave。候选较少时扩大关键词，按功能、目标用户和场景匹配程度排序。

阅读真实反馈

查找 App Store、Google Play 及讨论来源。评论、讨论和产品宣传分别记录。

查看带来源的报告

深入调查最多 10 个入选产品，保留其他候选及未入选原因，展示证据链接和采集覆盖。支持导出 JSON 和打印为 PDF。

从产品想法到竞品调研

  1. 描述产品想法，可填写已知竞品。
  2. 修改并确认 AI 的理解及实际检索关键词。
  3. 设置搜索次数、页面数、token 和评论上限，然后开始调研。
  4. 查看竞品排名、实际反馈、有证据的机会假设和下一步验证建议。

理解、关键词和抽取与最终报告可分别使用不同供应商。支持 OpenAI、Anthropic Claude、Google Gemini 和兼容 Chat Completions 的服务。

安装与本地运行

需要 Node.js 24+ 和 Python 3.9+，无需数据库或 Docker。

git clone https://github.com/pauline-zhang-star/IdeaProbe.git
cd IdeaProbe
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
# 在 .env 中设置 PYTHON_BIN=.venv/bin/python
npm start

打开 http://localhost:3210/，配置模型供应商和 API key。Bing RSS 默认启用且无需搜索 key，Tavily 和 Brave 可选。Windows 启动方式及配置详情请查看 README。

常见问题

IdeaProbe 有什么用途？

在开发产品前进行市场调研、竞品发现和评价分析。它把已有证据整理成带来源的报告，不能证明需求成立或预测产品成功。

IdeaProbe 免费吗？

软件采用 MIT 许可证，在本机运行。模型和搜索供应商可能按 API 使用量收费，本地版无需向本项目订阅付费。

可以使用 Claude、Gemini 或其他模型吗？

可以。理解与抽取、最终报告可分别配置供应商、模型 ID 和对应 key。自定义接口需支持 OpenAI Chat Completions 和 JSON 输出。

可以检索开源项目吗？

网页搜索可以发现 GitHub 仓库和其他开源工具。当前使用通用网页搜索源，尚未接入专用 GitHub Search API；覆盖取决于关键词和搜索供应商。

没有找到评价时会怎样？

仍然保留产品信息，并在采集覆盖中显示反馈缺失。不会编造评价，也不会把产品宣传当作用户反馈。

数据和 API key 保存在哪里？

任务和 key 保存在本机 .data/ 中。调研内容会发送给你选择的模型和搜索供应商，不发送给项目作者。这个公开页面仅提供产品说明。
