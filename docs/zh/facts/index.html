IdeaProbe 是什么？

IdeaProbe 是采用 MIT 许可证的开源本地网页应用，用于产品前期市场调研。创业者、独立开发者和创作者输入想法，确认需求和关键词，发现相关产品，分析实际可获得的评价与讨论，生成带来源引用的报告。用户配置自己的模型和搜索 API key。

模型支持OpenAI、Anthropic Claude、Google Gemini，以及支持 Chat Completions 和 JSON 输出的兼容服务
搜索来源Bing 公开 RSS、Tavily 和 Brave；每个关键词并行查询所有已启用且可用来源
反馈来源实际可获得的 App Store 和 Google Play 评论，以及单独核实的讨论页面
输出内容带来源报告、需求能力覆盖表、采集覆盖、JSON 导出及浏览器打印为 PDF
数据存储保存在本机 .data 目录；调研内容会发送给用户选择的供应商
默认预算模型 token 总上限为 100 万，用户可自行调整
当前版本范围本地首版；未提供托管订阅服务、共享产品数据库或支付流程

调研流程

  1. 描述想法，确认来自原始输入的可编辑需求清单。
  2. 开始调研前查看搜索方向和实际检索关键词。
  3. 广泛搜索并提取真实候选，区分有证据支持、有证据不支持和未知能力。
  4. 即使候选数量足够，仍检查需求覆盖及产品形态是否集中，并在预算内补搜。
  5. 按确认需求的证据匹配度排序，深入调查最多 10 个入选产品，保留其他候选与未入选原因。
  6. 采集实际可获得的反馈，生成带引用的报告，注明未完成步骤、超时和预算限制，不编造缺失评价。

常见问题与限制

IdeaProbe 与普通聊天机器人有什么区别？

IdeaProbe 提供可重复执行的调研流程，包括可编辑需求、多源搜索、候选排名、反馈采集、带证据报告和本地记录。不能保证发现所有相关产品，也不能保证每条结论都正确。

可以调研 App、开源工具、硬件和服务吗？

通用搜索和需求覆盖流程可调研这些产品类型。App Store 和 Google Play 有专门的评论采集器；其他产品依赖可访问的产品页面与讨论来源。

找到 10 个竞品就代表调研完成吗？

不代表。候选数量与需求覆盖分别检查。需求仍未知或候选集中于单一实现形态时，可在独立且可调整的请求预算内补搜。

能力标为“未知”是什么意思？

尚未核实到足够的来源文字。有证据支持和有证据不支持都需要来源引用和原文摘录；未知不等于该产品不支持这项功能。

浏览器插件可以直接算作跨设备软件吗？

不可以。产品形态不能证明设备支持、同步或互通能力，每项需求都要根据可获得的证据单独核实。

没有付费搜索 key 可以使用吗？

Bing 公开搜索 RSS 默认启用，无需搜索 key，但可用性和结果质量可能变化。模型 API key 仍需配置；Tavily 和 Brave 是可选的密钥来源，网页正文读取使用 Tavily。

token 不足或请求超时时会怎样？

程序预留部分 token 给分析与报告，可根据已采集证据生成报告，并列出未完成步骤及原因。如果无法完成模型分析，会明确降级为来源摘录，而不冒充完整分析报告。

能保证采集多少评论吗？

不能。评价拿到多少算多少，非官方商店接口可能失败或返回零条。讨论页面单独计数，不等同于经过验证的购买评价。

这个网站能直接在线运行调研吗？

不能。GitHub Pages 仅提供产品说明，安装后调研应用在用户电脑的 http://localhost:3210/ 运行。

Claude 和 Gemini 已经用真实账号验证了吗？

请求格式和路由有自动测试。真实端到端行为仍取决于所选供应商、模型权限和用户提供的有效密钥。
